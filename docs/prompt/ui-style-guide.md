# 叠叠裙界面风格（v7 · 粉发水手裙）

以 `game_assets/game2D_cat/assets/raw/dresssort/combo/smug-sailor-white.png` 为角色与画法基准。
原型图输出到 `../game_assets/game2D_cat/assets/raw/dresssort/mockup-v7/`。

## 角色

角色以 `Art/Cast/fullbody/full_apricot.png` 为脸和比例基准：杏橙发、茶褐椭圆眼、得意浅笑。
画法是日式电视动画赛璐璐：细匀黑线、平涂、淡腮红。换装页和首页用她。新发型和新裙子出在同一张全身像上，用户切成头 + 身体。

## 配色（十六进制 + 实物锚定）

- 页面底 `#F7FBFC`：刚倒出来的牛奶混一点清水
- 卡片 `#FFFFFF`：打印纸
- 墨字 `#2C2433`：紫黑墨水
- 主色泳池蓝 `#6FCFC8`：浅泳池水
- 按钮深蓝绿 `#2A9B96`：湿了的新铜绿
- 强调水蜜桃粉 `#F3A7B8`：水蜜桃果肉
- 香草卡片 `#FFF6EC`：香草冰淇淋
- 星 `#F0C84A`：金币那种黄

## 棋盘裙子小图（锁定无袖色块）

关卡里叠的是色块裙标，不是立绘缩小。规范见 `docs/prompt/board-dress-spec.txt`，基准 `Art/Icons/dress_black_ribbon.png`：无袖 A 字平涂、肩线缺口、2～3 色、细匀黑线。领口只放结或彼得潘领或三颗扣。

## 画法

- 细匀黑轮廓，跟立绘同一支笔
- 圆角胶囊按钮，白卡片，浅阴影
- 竖版 9:16 手机框，微信小游戏安全区：顶底各留空
- 中文用粗圆体，字少、字大、写对

## 页面

1. 首页：标题「叠叠裙」、角色、开始游戏、装扮、星星、已解锁
2. 选关：返回、「选择关卡」、三列关卡砖（奖励裙缩略图、锁）
3. 对局：关卡/主题/步数、四列叠裙、手持一件、撤回/随机/返回
4. 奖励：整理完成、问号礼盒、「收下并试穿」
5. 装扮：角色台、裙子/翅膀页签、4×2 衣柜、「保存搭配」
