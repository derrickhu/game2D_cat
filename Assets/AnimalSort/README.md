# 动物排队（Unity 2D）

竖屏 9:16 布局。棋盘固定 5 列 × 5 行，手里永远握着一只动物。

## 打开

1. 菜单 `AnimalSort / 创建并打开试玩场景`
2. Game 窗口比例选 **9:16**
3. 点 Play

## 玩法

- **点任意一列**：手里的动物插到该列最上面，该列最下面那只被顶出来，落到手里。列高始终是 5。
- 不用点动物本身，只有列的范围能点；手里那只和按钮区不参与命中。
- 把 5 列分别整理成 5 种动物，手里只剩五彩球，就过关。
- **移出**：手里的动物挪到右侧暂存位（再点一次换回来），暂存位有东西不算过关
- **撤回**：反向做一次移动
- **随机**：重新洗牌，每关 3 次
- **重开**：换一局

## 关卡生成

`SortGame.Generate` 从**已解状态倒着走**：初始是 5 列同类 + 手里五彩球，
反复执行「把手里的塞到列底、把列顶的拿到手里」这个逆操作 26 次。
因此任何一局都保证能在 26 步内解开，步数上限给到 60。

## 美术

`Tools/make_animal_sprites.py` 把 `Art/raw/*.png`（纯薄荷绿底的贴纸图）
处理成 `Resources/Animals/*.png`：

- 用**绿色过量**（G 高于 R、B 均值的部分）做色键，而不是 RGB 色距。
  狼的浅灰身体离底色只有 85，色距会把它抠掉一半；绿色过量是 0，安全。
  rembg 的 isnet-anime 会把整只熊吃掉，别用。
- 按 alpha 紧裁后统一缩放到 430px，居中贴到 **512×512** 画布。
  配合导入设置的 `PixelsPerUnit = 400`，每只动物在游戏里的高度完全一致，
  这是列对齐看起来整齐的前提。

## 动画

Unity 自带 **Animator + Animation**，`AnimalIdle` 做轻微晃动 + 呼吸缩放。
只有**手里那只**开 Animator，棋盘上的关掉，避免晃动破坏对齐。
